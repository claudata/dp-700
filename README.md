# DP-700 | Grupo de estudos Microsoft Fabric

Guia de estudos aberto em português (Brasil) para a certificação
**Microsoft Certified: Fabric Data Engineer Associate (DP-700)**.
Os nomes técnicos permanecem em inglês quando apropriado.

**Acesse o site: https://claudata.github.io/dp-700/**

## Conteúdo

- Roteiro de quatro semanas e teoria dos três domínios do exame.
- Diagramas, laboratórios e projeto integrador.
- Seis demos guiadas e sete scripts com referências oficiais.
- Simulado autoral de 15 perguntas, apresentado em etapas de três perguntas.
- Dicas de preparação, gestão do tempo e checklist para o dia do exame.
- Links para documentação, Practice Assessment e Exam Sandbox oficiais.

**Hosts:** Claudio da Silva e Sidney Siqueira,
ambos Sr Cloud Solution Architect — Microsoft.

## Como usar

Acesse o site e navegue pelo menu de seções. Para estudar offline,
baixe o arquivo `index.html` e abra-o em um navegador moderno.
Não há instalação, dependências ou etapa de build.

Os scripts são materiais de apoio: a página não se conecta ao Fabric nem
executa Python, PySpark ou KQL. Os laboratórios precisam de um ambiente
Microsoft Fabric com as permissões e os recursos indicados no guia.
Use somente ambientes de treinamento e dados não sensíveis.

O simulado é corrigido no navegador, sem envio de respostas a um servidor.
As respostas e marcações dos checklists não são salvas ao recarregar a página.
As referências externas precisam de internet e algumas exigem login.

## Publicação e manutenção

O GitHub Pages publica a raiz da branch `main`; `index.html` é a página inicial.
Para atualizar o site, edite esse arquivo e envie um commit para `main`.
Acompanhe a publicação na área **Actions** e em **Settings > Pages**.

Antes de publicar alterações, confira os links, a navegação, os scripts e o
simulado no navegador. Revise as fontes oficiais quando os objetivos ou as
políticas do exame forem atualizados.
